# Design System Prompts

This skill provides step-by-step prompts to setup and build a complete design system and website utilizing Tailwind CSS and shadcn/ui. 

## Included Prompts:
1. **[1-design-system-foundation.md](./1-design-system-foundation.md)**: Setup the foundations (colors, typography, global css) based on a design reference.
2. **[2-new-component.md](./2-new-component.md)**: Add a new component to the project using shadcn/ui.
3. **[3-new-page.md](./3-new-page.md)**: Build a new page based on a design screenshot.
